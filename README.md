## How to Download and Run

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/shrankhalalala/Subway-Surfers-AI.git
    ```

2.  **Navigate to the project directory:**
    ```bash
    cd <repository_name>
    ```
    (Replace `<repository_name>` with the name of the cloned directory)

3.  **Run the code:**
    The specific command to run the code will depend on how the project is structured.
    If it's a simple Python script (e.g., `main.py`), you might run it with:
    ```bash
    python pymath/lib/math.py
    ```
    (Or replace `pymath/lib/math.py` with the actual main script file if different)

    If the project has specific dependencies, you might need to install them first (e.g., using `pip install -r requirements.txt`). Look for a `requirements.txt` file or other setup instructions.
